# 宣传片制作

成片：[Road_to_AGI_游戏介绍.mp4](../art/Road_to_AGI_游戏介绍.mp4)，1920×1080、30 fps、60 秒，H.264 + AAC 双声道。配乐沿用仓库根目录的 `当然可以好问题.m4a`，无旁白。

所有录像和海报先统一为 BT.709、有限范围 YUV 4:2:0，再拼接和输出，避免浏览器 JPEG 录像的全范围标记使片尾 PNG 海报发灰。

## 字幕

宣传字幕统一用 Noto Serif SC 的 800 字重，实例化并重命名为 `R2A Promo Serif ExtraBold`。主色为浅金 `#F0D59A`，叠加低强度金色微光、深蓝字缘阴影和模糊椭圆晕影；字幕位于卡牌栏上方。片内游戏 UI、对话及角色立绘属于实机素材。

字幕内容、样式和逐帧剪辑点集中在 [tools/promo-edit.py](../tools/promo-edit.py)。字体来自制作游戏界面字体时保存的 `qa/font-source/NotoSerifSC.ttf`，许可与来源见 [字体说明](../game/public/assets/fonts/README.md)。支持通过 `--font` 指定同一字体的其他本地路径。

## 素材与重建

按照项目约定，新版原始录像保存在本机 `art-source/promo/current/clips/`，中间文件保存在 `qa/video-revision/build/`，不进入版本库。剪辑必须使用原始无字幕素材，不能把旧成片作为底片再次加字。此前的 `art-source/promo/clips/` 保留为旧素材，不再参与新版导出。

每个实机剪辑段对应同名的 `.mp4` 和 `.json`：`opening-strike`、`opening-dash`、`opening-charge`、`partners`、`skill-<伙伴 ID>`、`story-system`、`story-deepseek`、`region-1`–`region-4`、`trial`、`boss-1`–`boss-4`、`ultimate`。JSON 记录采集日期、游戏提交、主角图集清单的 SHA-256、采集帧率、剪入时间及真实游戏事件，事件时间均相对录像起点。

录制使用独立浏览器配置、临时本机 Vite 服务和游戏调试入口。拍摄时使用无敌模式及镜头缩放，由键鼠输入驱动战斗；Boss 镜头跳过前置小怪波次，编队镜头调用游戏原有整备界面，剧情调用原有对话。只在独立录制会话中布置场景，不修改游戏文件、正式存档、技能数值或敌人规则。Qwen 展示零消耗状态和蓄力突刺；Seed 在预设的受伤状态下展示回复生命及替身；GPT 展示另外两张卡和滑步的刷新。脚本核对九张卡的技能确认及对应效果，以及连击、滑步、蓄力和大招事件，并检查浏览器异常。

需要 Node.js、Chrome（可用 `CHROME_PATH` 指定）、游戏的 npm 依赖、FFmpeg/FFprobe、Python 的 numpy 和 fonttools。可复用本机 `qa/font-tools` 中的 fonttools。

在仓库根目录运行：

```powershell
node tools/promo-capture.mjs
python tools/promo-edit.py
```

仅重新录制指定镜头：`node tools/promo-capture.mjs skill-seed boss-3`；伙伴也可以简写为 `seed`。`--out <目录>` 可指定素材输出目录，剪辑时用 `--clips <目录>` 读取。录制文件有约 0.8 秒的动作前画面；剪入点取各 JSON 的 `marks.in`（默认 0.4 秒）。Boss 按冲刺、分身、反制和暴露事件选取剪入点，大招落拳对齐音乐的第 137 拍。可结合事件时间与抽帧再调整。

仅调整字幕后重导出：

```powershell
python tools/promo-edit.py --steps final
```

剪辑脚本可通过 `--clips`、`--work`、`--out` 指定其他路径。录制前要求游戏目录无未提交改动；导出时校验全部实机素材的游戏版本及图集清单，防止混入旧画面。同时校验九位角色覆盖、时间线连续、原始录像长度、各镜头帧数，以及成片的 1800 帧、分辨率、帧率和音轨。素材或剪入点变更后须重新执行 `--steps shots,final`，不能只重导出字幕。成功后才替换目标成片，并保存 `timeline.json`、`captions.ass` 和 `export-check.json` 供复核。还需抽帧检查技能画面、字幕可读性、对话位置、大招无字和完整海报片尾。
