# 宣传片制作

成片：[Road_to_AGI_游戏介绍.mp4](../art/Road_to_AGI_游戏介绍.mp4)，1920×1080、30 fps、60 秒，H.264 + AAC 双声道。配乐沿用仓库根目录的 `当然可以好问题.m4a`，无旁白。

所有录像和海报先统一为 BT.709、有限范围 YUV 4:2:0，再拼接和输出，避免浏览器 JPEG 录像的全范围标记使片尾 PNG 海报发灰。

2026-11-04 修订：战斗直接开场，删除首页镜头；原来的两段开场对话移至技能展示之后；九位伙伴各有独立的技能镜头；保留大招画面，移除“梁文锋 · 法天象地”字幕；片尾完整展示现有 16:9 横版海报。开场只保留“刺剑连击 · 滑步 · 蓄力突刺”，不显示“DeepSeek 刺剑动作 Roguelite”。

## 字幕

宣传字幕统一用 Noto Serif SC 的 800 字重，实例化并重命名为 `R2A Promo Serif ExtraBold`。主色为浅金 `#F0D59A`，叠加低强度金色微光、深蓝字缘阴影和模糊椭圆晕影；字幕位于卡牌栏上方。片内游戏 UI、对话及角色立绘属于实机素材。

字幕内容、样式和逐帧剪辑点集中在 [tools/promo-edit.py](../tools/promo-edit.py)。字体来自制作游戏界面字体时保存的 `qa/font-source/NotoSerifSC.ttf`，许可与来源见 [字体说明](../game/public/assets/fonts/README.md)。支持通过 `--font` 指定同一字体的其他本地路径。

## 素材与重建

按照项目约定，原始录像保存在本机 `art-source/promo/clips/`，中间文件保存在 `qa/video-revision/build/`，不进入版本库。剪辑必须使用原始无字幕素材，不能把旧成片作为底片再次加字。

原片使用游戏版本 `11b4c5f` 的录像，保留的素材为 `combat-a`、`combat-b`、`partners`、`story`、`cards-a`、`cards-b`、`lib`、`forge`、`zero`、`trial-fight`、`boss1`–`boss4`、`ult-c`（均为 `.mp4`）。本次在当前游戏版本补录 `skill-qwen`、`skill-seed`、`skill-gpt`，每段旁边的 JSON 记录触发时间和真实游戏事件。

补录使用独立浏览器配置、临时本机 Vite 服务和游戏调试入口，不改动游戏规则。Qwen 镜头展示零消耗状态和蓄力突刺；Seed 展示回复生命及替身；GPT 展示另外两张卡和滑步的刷新。脚本核对技能确认及对应效果，并检查浏览器异常。

需要 Node.js、Chrome（可用 `CHROME_PATH` 指定）、游戏的 npm 依赖、FFmpeg/FFprobe、Python 的 numpy 和 fonttools。可复用本机 `qa/font-tools` 中的 fonttools。

在仓库根目录运行：

```powershell
node tools/promo-capture.mjs
python tools/promo-edit.py
```

仅重新录制一个补充镜头：`node tools/promo-capture.mjs seed`。录制文件有约 0.8 秒的施法前画面；重新录制后需检查旁边 JSON 中的时间并相应调整剪辑点。

仅调整字幕后重导出：

```powershell
python tools/promo-edit.py --steps final
```

可通过 `--clips`、`--work`、`--out` 指定其他路径。脚本会校验九位角色覆盖、时间线连续、各镜头帧数，以及成片的 1800 帧、分辨率、帧率和音轨。成功后才替换目标成片，并保存 `timeline.json`、`captions.ass` 和 `export-check.json` 供复核。还需抽帧检查技能画面、字幕可读性、对话位置、大招无字和完整海报片尾。
