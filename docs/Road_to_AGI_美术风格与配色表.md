# Road to AGI 美术风格与配色表

ART-001。所有新资源开工前先对照这张表，细节规则在[设定文档](Road_to_AGI_游戏设定与美术制作规范.md)第2、8、10、11节。颜色是起点，以定稿的图为准。

## 共同规则

| 项目 | 规则 |
| --- | --- |
| 线条与上色 | 深色描边、三色赛璐璐阴影、少量柔光 |
| 光源 | 固定来自屏幕左上，所有方向相同 |
| 镜头 | 正交，方位角45度，俯角35.264度。标定场景见 `tools/reference3d/calibration.py` |
| 文字 | 图里不画文字和数字，由程序排版；服装上的单字母徽记（K、Z）可留 |
| 现实品牌 | 不画现实公司的名称和标志，每批图都要放大检查符号像不像某家公司的标志 |
| 绿幕 | 要走动画流程的实体身上不用亮绿和薄荷绿 |

## 敌我靠形状区分

| | 我方 | 敌方 |
| --- | --- | --- |
| 形状 | 曲线、长发、布料 | 硬边、平面、方块，没有人脸、皮肤和飘动的头发 |
| 阵营标记 | 角色自己的徽记和技能符号 | 归零印记：正六边形线框，上下各一个顶点，中间一条不碰边的短横杠。不用圆环加斜线 |
| 地面范围 | 实心细边，不透明度低 | 橙红外边加斜纹，预警范围等于伤害范围 |
| 精英 | 无 | 脚下双环，头顶淡奶油色小菱形，额外的几何嵌线 |

## 四幕的敌人和场景

| 大区 | 场景 | 敌人主色 | 敌人发光 |
| --- | --- | --- | --- |
| 缓存废港 | 蓝绿暗色港口、缓存箱、锈蚀机械 | 石板蓝、牛皮纸、旧黄铜、少量铁锈 | 冷青、青白 |
| 镜像书库 | 紫灰书架、裂镜、月白灯具 | 紫灰、旧象牙、暗梅、旧银 | 月白 |
| 梯度熔炉 | 深灰炉体、橙色热源、压印机关 | 钢灰、暖灰铁、橙灰 | 琥珀 |
| 零域 | 黑白几何环、少量冷蓝裂纹 | 纯黑白 | 少量冷蓝裂纹 |

地面要暗，原型的地面是 #233647。角色和敌人的主体要明显比地面亮，形体上缘有亮边。

## 界面

按钮和面板用 CSS 画，不用贴图。尽量用直角，只有摇杆保留圆形。

| 用途 | 颜色 |
| --- | --- |
| 按钮底 | `#0F2238`，70% 不透明，纯色，不加渐变 |
| 面板底 | `#10233B` 到 `#081425` |
| 线条和强调字 | 金 `#C8A45A`、亮金 `#F2DC9E`、暗金 `#7A6A45` |
